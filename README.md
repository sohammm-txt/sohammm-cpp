## Public Projects

### [PyPassVault](https://github.com/sohammm-txt/pypassvault)
A command-line password manager written in Python.
- Encrypts credentials with **AES-256-GCM**, using keys derived with **PBKDF2** (100,000 iterations, random salt)
- Fresh random nonce for every encryption
- Categorized vault files, built-in password generator using the `secrets` module
- Self-destruct after 20 wrong master password attempts
- Includes a test suite (`python3 tests.py`)

### [Steganography Tool](https://github.com/sohammm-txt/steganography-tool)
A Python tool that hides secret text inside PNG images using **LSB (least significant bit)** encoding.
- Works with any language through UTF-8 encoding
- Handles RGB, grayscale, palette, and RGBA images
- Capacity check, stop marker, and a simple menu interface
- Built with Pillow
